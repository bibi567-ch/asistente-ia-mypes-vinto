# Documentación histórica

Los archivos de `referencias_historicas/` son duplicados/propuestas anteriores y no están vigentes. Se preservan para rastrear decisiones y diferencias con las versiones actuales. No presentarlos como especificación activa. Los documentos activos están en `docs/01`–`docs/13` y se enlazan desde el README de la raíz.

La propuesta anterior de Spring Boot/PostgreSQL se conserva como antecedente; el equipo propone Node.js/Express/PostgreSQL. El SAD v1.1 también se conserva con su versión y una nota de migración. Las decisiones antiguas sobre MongoDB o sincronización no se consideran aprobadas para la arquitectura actual.
