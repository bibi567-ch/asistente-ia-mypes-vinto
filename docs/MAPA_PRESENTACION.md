# Mapa del trabajo

El proyecto es un prototipo de asistente conversacional offline para anotar una venta y consultar el saldo local en MYPES del centro de Vinto. No es un sistema de almacén.

**Equipo:** Eva Lizeth Chino Quispe, Christian Gonzales Mamani, Marializ Mamani Quispe, Kevin Jhonathan Rocha Rojas, Luis Gerardo Lazo Bustamante.

## Cómo se reparte entre las materias

| Materia | Qué aporta este repositorio |
|---|---|
| Investigación I | El [perfil](perfil/Perfil_final.md) y el [cronograma](Cronograma_final.md). El alcance queda en el registro de la venta y el saldo local. |
| Arquitectura de Software | El [documento de arquitectura](03_SAD_Arquitectura.md) y los [diagramas](../diagrams/README.md). El diagrama de contenedores sigue el código actual: Node.js y PostgreSQL. El SAD v1.1 conserva la versión que hablaba de Spring Boot. |
| Tecnologías en Internet | La API en `backend/`: login, catálogo y PostgreSQL. PostgreSQL no es una base NoSQL. |

## Estado del producto

En el repositorio hay login de propietario y catálogo de un negocio.

No hay aplicación Android, ni registro de la venta, ni descuento del saldo, ni voz.

Figma muestra las pantallas previstas. No es la aplicación.
