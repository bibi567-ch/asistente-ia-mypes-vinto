## Reglas

- Toda evidencia debe tener fecha y descripción.
- Las capturas deben mostrar el contexto suficiente para ser verificables.
- No se deben incluir datos personales reales de comerciantes.
- Las métricas deben acompañarse del método de medición.
- Si una evidencia no existe, debe registrarse como pendiente.
