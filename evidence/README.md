# Evidencias

Guardar aquí registros revisables y anonimizados: capturas de interfaz, respuestas de API, procedimientos de validación y mediciones. Cada archivo debe incluir fecha, commit, entorno, pasos y qué requisito acredita. No guardar secretos, identificadores personales, datos de comerciantes ni audio identificable.

Las métricas de rendimiento, reconocimiento de voz, usabilidad, seguridad y sincronización no se consideran verificadas hasta que se adjunte un procedimiento repetible y su resultado.
