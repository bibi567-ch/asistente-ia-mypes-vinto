# Evidencias de la primera entrega

Esta carpeta reúne evidencias verificables del avance documental y del prototipo UX/UI.

## Convención de nombres

Usar el formato:

`E##_<criterio>_<descripcion>.<extension>`

Ejemplo: `E01_Figma_FlujoRegistroVenta.png`

## Evidencias esperadas

- Captura del prototipo público en Figma.
- Capturas de vistas desktop y mobile.
- Capturas de componentes y variantes del sistema de diseño.
- Capturas de estados de carga, vacío, error y éxito.
- Exportación legible de los diagramas C1, C2 y casos de uso.
- Evidencia de revisión de enlaces y permisos.

> No se deben incluir capturas de pruebas, métricas o funcionalidades que todavía no hayan sido ejecutadas o verificadas.
